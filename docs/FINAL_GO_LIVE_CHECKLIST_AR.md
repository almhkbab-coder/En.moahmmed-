# قائمة التحقق للإطلاق الميداني النهائي والتشغيل الحي (Final Go-Live Checklist)
## عيادة الدكتور محمد أحمد الصياد - جراحة العظام والمفاصل الصناعية

---

## 1. التجهيزات الفنية الأساسية (Technical Pre-Flight)

- [ ] **الترقية والتوافق:** التأكد من تشغيل النظام على **Django 5.2.19 LTS** و **Python 3.12+** و **PostgreSQL 18**.
- [ ] **إيقاف وضع التطوير:** التأكد من ضبط `DEBUG=False` في ملف `.env` الإنتاجي.
- [ ] **مفتاح الأمان السري:** التأكد من أن `SECRET_KEY` مولد عشوائياً (بطول 50+ خانة فريدة) ولا يحتوي على بادئة `django-insecure-`.
- [ ] **مفتاح تشفير بيانات المرضى:** التأكد من توليد مفتاح فريد لـ `PATIENT_DATA_ENCRYPTION_KEY` وحفظه في خزنة كلمات مرور آمنة خارج الخادم.
- [ ] **قاعدة بيانات الإنتاج:** التأكد من أن قاعدة بيانات الإنتاج `alsayyad_clinic_db` معزولة تماماً ولم تُطبق عليها أوامر تصفير الـ Staging.
- [ ] **ترحيل الجداول:** اكتمال تنفيذ أمر `python manage.py migrate --settings=config.settings.production` بنجاح 100%.
- [ ] **جدول التخزين المؤقت:** إنشاء جدول الكاش المشترك `python manage.py createcachetable clinic_system_cache`.
- [ ] **تجميع الملفات الثابتة:** تنفيذ `python manage.py collectstatic --noinput` واكتمال نسخ ملفات التصميم والأيقونات.
- [ ] **فحص النشر الأمني:** اجتياز فحص `python manage.py check --deploy` دون أي أخطاء حرجة.

## 2. شهادات الحماية والنطاق الجغرافي (Domain & SSL/TLS)

- [ ] **ربط النطاق (DNS Records):**
  - توجيه سجل `A` للنطاق `alsayyad-clinic.ye` إلى عنوان IP الخادم الثابت.
  - توجيه سجل `CNAME` للنطاق `www.alsayyad-clinic.ye`.
- [ ] **شهادة الأمان SSL/TLS:**
  - إصدار شهادة Let's Encrypt وتفعيل التجديد الآلي عبر Certbot.
  - التحقق من عمل التحويل التلقائي من HTTP إلى HTTPS بنجاح (301 Redirect).
- [ ] **ترويسات الحماية:** التحقق من ظهور ترويسات `Strict-Transport-Security` و `X-Frame-Options` و `X-Content-Type-Options`.

## 7. خطة التراجع السريع عند الطوارئ (Emergency Rollback Plan)

في حال حدوث خلل تقني غير متوقع عند توجيه النطاق:
1. تحويل توجيه Nginx إلى صفحة الصيانة المؤقتة (Maintenance Page):
   ```nginx
   return 503;
   error_page 503 /maintenance.html;
   ```
2. استعادة آخر نسخة احتياطية صالحة تم أخذها قبل الإطلاق:
   ```bash
   pg_restore -U alsayyad_db_user -d alsayyad_clinic_db --clean /var/backups/clinic/pre_launch.dump
   ```
3. مراجعة ملف السجلات `/var/www/alsayyad_clinic/logs/production.log` لتحديد سبب الخلل ومعالجته قبل إعادة المحاولة.
